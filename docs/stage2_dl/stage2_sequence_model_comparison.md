# Stage 2 Sequence Model Comparison: LSTM vs Transformer

## 1. Overview
This report compares the performance of the longitudinal sequence classification branch using two recurrent/attention-based architectures: **LSTM** and **Transformer Encoder**.

Both models were trained and evaluated on the exact **SAME synthetic dataset**, utilizing the SAME 150-patient unseen test set, and targeting the SAME binary outcome (Responder vs. Non-Responder).

## 2. Experimental Constraints
- **Data Scaling**: Both models fitted scalers strictly on the training partition.
- **Leakage**: Both models used patient-level splits to guarantee zero overlap.
- **Selection Metric**: Both pipelines selected the best epoch checkpoint using Validation Macro F1.

## 4. Interpretation and Conclusion

Based directly on the actual metrics generated by the unseen test set:

**The Transformer Encoder performs better than the LSTM across every single tracked metric on this specific dataset.**

### Key Advantages Observed:
1. **Responder Identification (Recall)**: The Transformer correctly identified ~87.1% of true Responders compared to the LSTM's ~82.3%, a significant improvement in reducing false negatives for the harder-to-predict class.
2. **Overall Balance**: The Transformer achieved a highly balanced Macro F1 (0.8442) vs the LSTM (0.8164).
3. **Parameter Efficiency**: The Transformer accomplished these superior metrics with fewer trainable parameters (12,866) compared to the LSTM (17,538), likely due to the aggressive projection down to `d_model=32` and leveraging multi-head attention to model feature relationships concurrently.

While neither architecture is universally better across all medical domains, for this specific synthetic short-sequence (8 time steps) tabular dataset, the attention mechanism of the Transformer clearly mapped the chronological dependencies and feature interactions more effectively than the recurrent state updates of the LSTM.
