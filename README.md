# Personalized Precision Oncology

## Overview
AI system predicting oncology treatment outcomes.

## Stage 1 ML capabilities:
- Toxicity risk prediction
- Therapy response prediction
- Explainable AI using SHAP
- Patient-level prediction

## Technology:
- Python
- Scikit-learn
- XGBoost
- LightGBM
- SHAP

## Pipeline:
Dataset
↓
Cleaning
↓
EDA
↓
Feature Engineering
↓
Model Training
↓
Tuning
↓
Evaluation
↓
Explainability
↓
Prediction

## Future Development
Stage 2 Deep Learning will extend the system using imaging and sequence data.
